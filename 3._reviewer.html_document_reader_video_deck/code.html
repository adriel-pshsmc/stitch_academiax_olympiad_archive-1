Theorem IV.2 (The Generalized Spectral Decomposition & Jordan Normal Form) Core Theorem

Let V be a finite-dimensional vector space over an algebraically closed field K = ℂ, and let T ∈ End(V) have distinct eigenvalues λ₁, λ₂, …, λₖ with characteristic polynomial χ_T(t) = ∏ (t - λᵢ)^{mᵢ}. Then V decomposes uniquely into the direct sum of its generalized eigenspaces:

V = K_{λ₁}(T) ⊕ K_{λ₂}(T) ⊕ ⋯ ⊕ K_{λₖ}(T)
where K_{λᵢ}(T) = ker((T - λᵢ · I)^{mᵢ}) = ker((T - λᵢ · I)^{dim V}).
Demonstration of Canonical Form & Nilpotent Splitting

Proof. For each eigenvalue index i ∈ {1, …, k}, let Wᵢ = K_{λᵢ}(T). By the Primary Decomposition Theorem (applied directly to the minimal polynomial μ_T(x) = ∏ (x - λᵢ)^{rᵢ} where 1 ≤ rᵢ ≤ mᵢ), the polynomials qᵢ(x) = μ_T(x) / (x - λᵢ)^{rᵢ} are pairwise coprime. Hence there exist polynomials a₁(x), …, aₖ(x) ∈ K[x] such that:

∑_{i=1}^{k} aᵢ(x) · qᵢ(x) = 1

Evaluating this identity at operator T yields projections Pᵢ = aᵢ(T)qᵢ(T) satisfying P₁ + ⋯ + Pₖ = id_V and Pᵢ Pⱼ = δ_{ij} Pᵢ. Consequently, each subspace Wᵢ = im(Pᵢ) is invariant under T. We may express the restriction as:

T|_{Wᵢ} = λᵢ · I_{Wᵢ} + Nᵢ where Nᵢ^{rᵢ} = 0

Since Nᵢ is a nilpotent linear operator on Wᵢ, there exists a cyclic basis of generalized eigenvectors transforming the block matrix representation into direct sums of elementary Jordan blocks J_d(λᵢ):

J(T) =
[ λ₁ [ 0 [ 0 [ ⋮
1 λ₁ 0 0
0 1 ⋱ 0
⋯ 0 ] ⋯ 0 ] ⋯ 1 ] ⋯ λₖ ]
Diagonal contains spectral eigenvalues; superdiagonal constitutes unit nilpotent couplings.

This monograph provides a rigorous self-contained derivation of the Jordan Canonical Form without resorting to the theory of modules over principal ideal domains. Utilizing purely spectral projections and nilpotency indices, the exposition establishes generalized eigenspace decomposition for complex finite-dimensional endomorphisms. Complete with detailed algebraic diagrams, five fully solved Olympiad-level matrix characterization lemmas, and historical notes reflecting Cauchy-Laplace operator correspondence.
